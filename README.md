# Radiology Lean GTM Builder (MVP)

**Working prototype** for founders building go-to-market strategies in radiology and medtech.

This is an early MVP. We are collecting feedback from founders and operators.

### How to use
Open the live demo (link will appear once GitHub Pages is enabled) or open `index.html` locally in any browser.

Enter a product description, target segment, stage, and resources. The tool generates a lean GTM sketch focused on protecting runway.

### Feedback
Early testers who share feedback will receive **3 months of free usage** when the full product launches.

Please tell us:
- Which matched examples felt useful
- Which recommended actions are realistic
- What is missing or should be improved

Thank you for testing.
